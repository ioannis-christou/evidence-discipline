What this is

A plant performance layer that sits on top of the systems a factory already runs — an OEE system such as Evocon, an ERP such as SAP or SoftOne, an MES, a control panel, HR time records, utility meters — and turns them into one set of numbers that Operations, Finance and Commercial can review together.

The charts are the easy half. The half that takes twelve years in a plant is below: what each number actually means, which denominator it uses, where two systems disagree about it, and what to do when it moves. That definition layer is the deliverable; the dashboard is how it is delivered.

The four reconciliations

These are the ones normally left implicit, and the ones that make two people quote different numbers for the same month.

1. Where the GE target comes from. It is not a number somebody chose. It is built upward from standard times — start-up, intermediate CIP, long-cycle wash, changeovers — subtracted from calendar time, with the remainder taken at a 94% OEE allowance. What survives is the output the line can actually deliver; the target is that over the calendar. Two consequences follow. The target differs per line because the wash cycles differ. And if a wash cycle or a changeover standard changes, the target must be recomputed, not carried forward — a target inherited from last year is measuring last year's plant.
2. Two OEE sources that disagree. The OEE system measures at the machine. The control panel reconstructs the same period from production records. They rarely match, and the gap is almost always how planned stops are classified. This dashboard shows both, labelled, and never averages them — an average of two definitions is a third number that measures nothing. Use the OEE system for trend, the control panel for reconciliation against volume, and treat a widening gap between them as its own signal: it means stop classification is drifting on the floor.
3. Plan adherence when the plan moves. Adherence is measured against the plan as frozen at the start of the period, not the latest revision. Measured against the latest revision, a plan rewritten daily scores 100% forever and the metric is dead. Weekly is the honest grain: monthly hides reshuffling inside the month, daily punishes normal sequencing decisions that cost nothing.
4. Labour per tonne, comparable across lines and years. The numerator is hours inside a fixed boundary — the same direct and indirect categories every month, or the series compares nothing. The denominator is saleable tonnes, not gross throughput, or rework flatters the number. It is reported at three levels (plant, production, repack) and those three are never combined, because a plant figure that mixes an aseptic line with a hand-packing table is an average of two different jobs.

Data lineage

Each tab names its source in the caption. Nothing is typed in by hand: every figure traces to a system of record, and where two systems cover the same quantity, both are shown rather than silently reconciled. Where a measurement starts mid-period — tank metering, a new sub-meter — the series says so instead of back-filling an estimate.

Absent is not zero. A month with no recorded value is shown as absent, never as a zero that would drag an average down. This matters most in the per-tonne series, where a zero denominator would otherwise produce a confident and wrong number.
